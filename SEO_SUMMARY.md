## 🔍 How to Verify SEO is Working

### **Method 1: View Page Source**

1. Visit your website
2. Right-click → "View Page Source"
3. Look for `<meta>` tags in the `<head>` section
4. You should see keywords like "Riviera Maya", "Tulum", etc.

### **Method 2: Google Rich Results Test**

1. Go to: https://search.google.com/test/rich-results
2. Enter: https://diagonalstudio.mx
3. Check for "Organization" and "LocalBusiness" schemas

### **Method 3: Browser Extension**

1. Install "SEO Meta in 1 Click" (Chrome/Firefox)
2. Visit your website
3. Click the extension icon
4. Review all meta tags and structured data
